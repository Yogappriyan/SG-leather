70. FIRESTORE SECURITY
============================================================

Security is critical.

Public users:

Can read active products.

Can read active categories.

Can read active banners.

Can create their own orders according to validation rules.

Can read only their own orders.

Cannot modify products.

Cannot modify categories.

Cannot modify banners.

Cannot modify offers.

Cannot modify admins.

Cannot access other customers' private data.

Only authorized admins can manage products, orders, categories, banners, offers, reviews and settings.

Use:

isAdmin()

based on:

request.auth.uid

and:

admins/{uid}

active == true

Never use:

allow read, write: if true;
